### Sobre mí

Construyo interfaces web y mobile rápidas, accesibles y cuidadas en el detalle. Me enfoco en el frontend: diseño de componentes, estado de la aplicación, rendimiento y que la experiencia se sienta bien en cualquier pantalla.

- Desarrollo **SPAs, landings y paneles** con React + TypeScript + Vite.
- Llevo la misma base a **mobile** con React Native (Expo) y Capacitor.
- Trabajo de punta a punta con negocios reales a través de **Genesis Code Studio**.
