### About me

I build fast, accessible web and mobile interfaces with attention to detail. My focus is the frontend: component design, application state, performance, and making the experience feel right on any screen.

- I build **SPAs, landing pages and dashboards** with React + TypeScript + Vite.
- I take the same foundation to **mobile** with React Native (Expo) and Capacitor.
- I ship end-to-end products for real businesses through **Genesis Code Studio**.
